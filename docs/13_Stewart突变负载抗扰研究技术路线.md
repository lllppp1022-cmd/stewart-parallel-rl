# Stewart突变负载抗扰研究技术路线

研究问题：在保持姿态或执行已验收的小范围轨迹时，未知突变外力/力矩如何影响位姿、恢复、驱动力和闭链约束；强传统控制之外是否仍存在值得学习且可安全调节的误差。

## 本轮：Phase 2A

仅构建外载平台与C0/C1/C2配对实验，不安装或训练PPO/SAC/BC，不增加C3控制器。沿用原±400 N支链限制、1 ms积分、1 kHz控制、安全门槛及受限保持。所有新任务在独立目录运行，旧模型和控制文件保持SHA256冻结。

先对世界竖向力−2/−5/−10 N、正负世界X力矩0.1/0.25/0.5 N m做有终止预算的预检；同一方向失败停止盲目扩大。正式矩阵、容差与控制配置在读取正式评价结果前冻结。用已有轨迹及无外载配对比较，不把早停任务的短窗口RMSE与完整6秒任务直接排名。

## Phase 2B：强传统抗扰基线与可学习性（仅计划）

候选C3为C0加有界扰动观测补偿。先推导观测器和滤波、检查参数辨识误差、延迟、饱和与稳定性，再做受限真实动力学实验；不得读取外载真值。和冻结C0/C1/C2公平比较，不故意削弱原控制器。

比较3维任务空间残差力与6维执行器残差力的小幅正负动作，审计Jacobian转置力映射、力余量、条件数、变化率和闭链约束。进入2C须有可重复、可恢复任务，量化最强传统基线剩余误差，证明小幅动作确有益且约束保持，并冻结有界计算预算。仅观察到非零误差不足以证明RL有收益。

## Phase 2C：残差MDP（仅计划）

先验证Gymnasium接口、零动作完整复现传统基线，区分1 kHz物理/控制与20或50 Hz学习决策。第一版3维任务残差，6维仅作后续消融。观测采用位姿误差（SO3）、速度、支链行程/速度、传统控制输出、上一动作和当前参考。不提供真实扰动参数、加载时刻或未来信息。奖励分项记录，避免提前保护、不运动或延长任务获取额外奖励。

## Phase 2D：有界PPO Pilot（仅计划）

先Home小力，再力矩，再动态参考，再加载时间/幅值/方向随机化，最后轻度模型失配。先1024～2048决策烟雾测试，再按预先冻结门禁决定预算；不得依据期望直接长训练。记录实际决策与物理积分数、随机采样、实际残差、奖励、安全、更新和checkpoint。

## Phase 2E：历史反馈与泛化（仅计划）

比较单时刻/历史观测PPO、可选显式估计器+传统控制；SAC仅在有证据和预算时考虑。分开训练、验证和未开启最终测试，覆盖未见负载、时间、轨迹、模型参数与持续时间。多个独立训练种子，确定性重复不能冒充独立随机任务。

## Phase 2F：正式评价与工程展示（仅计划）

C0/C1/C2/C3与残差PPO、历史残差PPO在配对条件下比较峰值、加载/卸载恢复、积分误差、控制努力、约束、完成率、样本成本和泛化。记录未恢复、右删失和失败；不能只看Reward或剔除失败。PPO若不能稳定超过强传统基线，完整保留负结果。

所有阶段沿用PARTIAL PROXY QUERY描述，不宣称整机碰撞认证、形式化安全或实机认证。本轮完成后暂停，Phase2B及以后的实验需用户审核再开展。
