## 冻结控制律审计

C0源码`src/phase1/controllers.py`明确为`reference.ff + Kp*(q_ref-q) + Kd*(dq_ref-dq)`：已有参考速度参与速度误差反馈，`reference.ff`是沿参考构型计算的静态平衡力。不能称C0完全没有速度项。C3/C4的观测器使用名义M、D、K估计闭环等效扰动；C4还补偿Yaw；fourDlead对因果扰动估计作20Hz受限超前。它们没有单独下发本次新增的`Dzz*v_ref + Mzz*a_ref`显式参考动态广义力。

新增项意在补偿名义被动阻尼及运动惯性需求，区别于Kd速度误差反馈；不新增重力。它仍是局部Z等效模型，不是Stewart全逆动力学；支链耦合、柔性闭链、几何变参和控制离散效应仍有残差。

## 参数来源与单位

`Wff_z = kv*v_ref + ka*a_ref`，kv=570.453024115 N·s/m、ka=50.1853287955 kg。来源：冻结Home名义约束切空间模型`__PROJECT_ROOT__\results\runs\phase2b1_20261028_v1\nominal_task_model.json`，SHA256 `5b0c06910b00ff93c4a0d6512fe5e85942650d67b9b5af358583e17adfcac6c7`。通过`E*T=0`、`Jsite*T=I`计算`Mtask=T.T*Mfull*T`和`Dtask=T.T*diag(damping)*T`。平台20kg不是包含支链运动贡献的50.185kg任务空间等效质量。

0～50mm的26个名义位置审计：Mzz范围50.185328620～50.230618857 kg，Dzz范围570.453008749～574.692471674 N·s/m。位置变化存在，但这条纯Z路径上幅度有限；没有宣称Home值在全工作空间精确。

## 因果解释的边界

相关系数属于统计描述，切空间M/D属于简化名义解释。只有相同轨迹/物理模型/预算、只改变前馈结构的配对实验才支持控制干预效应。FF-V减少误差，FF-VA进一步减少，支持名义参考动态补偿不足是本组快速Z误差的重要来源；并不证明所有误差都是阻尼，也不能把无滞后名义误差说成未知执行器造成。

本轮只验证MuJoCo纯世界Z正向50mm任务。887个独立网格凸包查询配对、103个连接组件排除仍属PARTIAL覆盖；30个被动铰链没有原生机械硬止挡。无原生接触不等于全几何无碰撞，更不等于实机安全认证。
