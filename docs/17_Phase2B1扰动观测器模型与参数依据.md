# Phase2B-1扰动观测器模型与参数依据

## 为什么选择局部动量残差

完整非线性DOB需要在闭链中一致处理被动自由度、惯性/速度项、约束反力和可测状态；直接取真实plant的qacc/bias/constraint force不符合本项目观测边界。直接用位姿误差乘增益也不构成力观测。ESO同样需要经验证的输入/加速度关系，本轮没有必要再并行实现一套。

采用独立名义模型在Home的闭链切空间推导6轴低阶模型，再构造动量残差。它不需要直接对速度除dt求加速度，而用经带宽限制的动量增量。它估计局部等效输入扰动，可能包含模型误差、软约束效应和真实外载，不能标成精确真实外力或力传感器测量。

MuJoCo通用惯性、偏置和约束力关系参照[官方动力学说明](https://mujoco.readthedocs.io/en/latest/computation/index.html)；实际3.17.0 API参数以本机绑定文档和运行结果为准。官方只说明引擎关系，并不为本项目的局部近似和控制性能作保证。

## 名义闭链模型推导

原模型nv=42，Home的36个独立等式约束构成E，平台upper_center的世界线/角速度Jacobian为J_site。求42×6映射T，使E T=0且J_site T=I。只在独立名义scratch MjData中计算；不得修改live状态。

M0=T^T M_full T；M_full通过名义mj_fullM获得，包含模型中全部关节/刚体惯性与相应armature。D0=T^T diag(dof_damping)T，保留交叉轴项。名义模型摩擦损失为0、没有tendon、流体密度/黏度为0；局部阻尼没有暗中忽略这些非零参数。K0通过独立名义位姿的±1e-6局部扰动，对T(q)^T(bias-passive)做中央差分。该scratch运动学参数扰动不是机器人执行或RL动作敏感性试验。

W0=J_home^T F_balance，F_balance仍来自冻结原控制器的名义静力平衡。T的约束误差约3.3e-16，平台速度映射误差0；M0正定，W0与直接投影名义重力的最大差约2.6e-6。矩阵及完整精度结果在run的nominal_task_model.json。其平移块单位kg、转动块kg m^2、交叉块kg m，不能将混合单位矩阵所有数值都叫质量kg。

局部关系为：

M0 v_dot = W_known - W0 - K0 x - D0 v + d_equivalent

x=[p-p_home, Log(R R_home^T)]，v=[世界线速度, 世界角速度]，广义力矩参考点为upper_center。完整6×6矩阵保留XY/Yaw耦合。大角度时Log坐标导数不等于世界角速度，变惯性、非线性速度耦合和软闭链模式未被精确补偿，而是模型残差；不能宣称完整全工作空间动力学观测。

## 因果观测离散式

令p_momentum=M0 v，前一步f_nom=W_known-W0-K0 x-D0 v，则：

r_k = [r_(k-1) + omega*(M0*(v_k-v_(k-1))-dt*f_nom_(k-1))] / (1+omega*dt)

这是动量残差的一阶低通隐式更新。在理想局部模型下r对等效扰动是一阶滤波响应。当前测量与上一物理步真正下发的总命令进入更新，当前计算的补偿不被误当成外力；控制器也不读取实际执行器力真值来作弊。本轮名义直接力执行器增益1且未施加增益失配，已知命令可作为名义驱动；实际增益失配会成为等效模型残差，尚未在本阶段验证。

观测1kHz，带宽候选5/15/30 rad/s，时间常数约1/omega；带宽单位不能换成Hz而不除2pi。初始化r=0，第一次测量只初始化速度；第二次更新前必须有上一命令，否则拒绝。限幅和Reset规则见文档16。

动量滤波不等于没有噪声放大。高频速度噪声增益仍与M0*omega有关，当前是理想无噪声测量。未来传感器噪声、延迟、质量/阻尼失配和更大姿态都需要独立验证，不能据本轮结果保证泛化。

## 独立模型与观测验证

在旧Phase2A无外载Home/Roll/Pitch/Z+Roll真实轨迹上验证局部预测残差，没有拟合实际扰动参数或用测试标签回归系数。独立读取速度差只用于离线验证误差，控制器本身不读取实际qacc或下一状态。

结果见results/phase2b1_nominal_model_validation.csv/json：Home滤波等效Fz偏置约8e-5N；无外载动态轨迹的局部Fz残差RMS约8e-4N，Roll/Pitch力矩约1e-3N m以内。验证覆盖实际约±0.402度姿态与Z约2.5mm，不能由此宣称整个原工作区或更大幅值都有效。

带宽选择只在新开发集C0的零载、−5N、+0.25N m物理日志上做因果回放。回放只使用测量状态和历史下发力，观测器没有外载参数；真实外载只用于外层离线方向、稳态误差、响应及衰减门禁和RMSE评分。门禁预先冻结为零载偏置<0.5N/0.02N m、稳态相对误差<=50%、响应/衰减<=1s、方向正确。全部带宽结果均保存，未只保留最佳项。

通过观测器门禁后才运行实际补偿增益0.5/1两档开发试验。随后冻结参数，再打开最终历史基准与独立测试。开发选择与最终评价CSV分开；最终模型参数不反过来调整。

## 可测性与未确认项

平台p/R/v和支链位置/速度在仿真中作为理想传感器反馈。冻结C0的Jacobian还使用全链关节坐标；被动关节编码器、平台6D测量方案、带宽、噪声和标定在真实硬件上均UNKNOWN，本轮没有完成这些传感器工程。名义引擎内部M/bias只用于离线推导名义模型，实际plant内部动力学不进入C3。

本轮不声称新观测算法、严格稳定性证明、完整闭链反力重建或实机外力感知。局部模型验证通过意味着可以研究这一受限仿真基线，不代表PPO有必要或有保证。
