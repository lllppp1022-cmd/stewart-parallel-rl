# Phase 2C-9B 准入修正与实验协议

实验目录为 `results/runs/phase2c9b_20261112_v1`，日期为2026-11-12。原Phase 9在Home分类准确率100%的条件下仍要求提高5个百分点，存在天花板效应。本轮按用户要求把分类结果作为研究动机，安全与环境正确性通过后实施匹配PPO。

## 训练前冻结

四份JSON格式YAML分别记录质量、任务、PPO和评价规则，SHA在实验目录 `config_freeze.json`。训练质量为20、20.6、21.2、22 kg。21.6 kg只作分层预检。最终包含20 kg回归与20.3、21.5、21.8 kg未见质量，两类不同联合参考，以及新的加载卸载时刻和方向。参考几何使用既有审核缓存，参考参数和外载组合在训练前冻结。最终策略只在共同预算与所有种子确定后评价。

硬安全检查沿用1 ms物理、50 Hz动作、二维每轴±0.05 N·m、共享附加力±5 N、20 N/s及原生±400 N。质量只在reset时改变，主惯量按相同比例缩放，控制器仍使用20 kg名义模型。分层预检覆盖Home、纯Z、联合姿态，以及训练/开发/最终任务上的零动作和有界随机动作。一条随机序列通过只支持该次运行。

## 公平训练

单帧58维，历史为最近5帧290维，首尾80 ms，当前帧相同。两类隐藏层均为64×64，实际总参数量分别记录。奖励固定V2。独立任务RNG使用原Phase 8实现，同一训练种子的任务和质量序列逐条核对。网络输入不同，全参数初始SHA分别记录。

六组先各8192决策，全部合法且无保护，Actor/Critic更新、奖励和GAE可复算，开发集每个种子两类IAE及XYZ均值不超过初始150%，并且每个方法族至少有一个开发IAE或共同回报改善，允许两类同时扩至32768。这里150%的严重退化护栏和“每方法族至少一项改善”是本轮实现选择，训练前写入配置。它不要求PPO在Pilot超过经典方法。

历史收益验收采用至少两个种子各在至少两个最终任务同时改善加载和卸载IAE各1%，全任务安全且峰值、角速度、XYZ及力代价在匹配比较对象110%以内。该具体量化阈值由本轮实现设定，最终结果前冻结。强适应成功还需按相同标准超过经开发整定的经典适应补偿。所有种子和失败保留，微小收益不作统计显著性声明。

## 经典控制

冻结基线、同权限50 Hz PD、PD加泄漏有界积分。三个积分增益候选0、10、30，只用两个开发任务选择安全且加载/卸载总IAE最低的方案。积分幅度±0.025 N·m，饱和时抑制积分累积，全部经原动作和共享预算。选择规则在最终测试之前执行并保存。

## 恢复与归档

显式预算边界保存任务RNG、Python/NumPy/Torch随机状态、优化器和checkpoint。恢复验证重复同一保存边界，对照真实动作、物理状态及最终参数。任意回合中间崩溃不伪称无缝恢复，应归档异常。完整回合与预算尾部片段分别记录。
