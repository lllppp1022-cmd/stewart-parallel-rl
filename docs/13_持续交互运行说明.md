# Stewart 持续交互运行说明

增强入口默认持续运行，不再设置45秒仿真或600秒墙钟退出上限。原Phase1.5入口和历史实验保持原样。

## 启动

在PowerShell或VS Code终端执行：

```powershell
cd __PROJECT_ROOT__
& D:\miniconda\envs\stewart_rl\python.exe scripts\teleop_stewart_enhanced.py
```

关闭MuJoCo机器人窗口或控制面板中的任意一个窗口，均会请求停止物理循环，保存本回合数据，并关闭另一窗口。控制面板Quit或Q/Esc同样可退出。关闭时请等待归档结束，不要强行结束进程。

“持续运行”指无预设时间截止；Home/Hold会继续动力学保持，Pause暂停物理积分，安全故障仍按原规则进入保护保持并锁定，需Reset新建回合，不会为了持续运行而解除保护。

操作W/S（Z）、A/D（Roll）、I/K（Pitch）、R（Home）、Space（Hold）、P（Pause）时，先点击控制面板。机器人原生Viewer有自己的快捷键，例如W会切换线框，不能当作控制面板的W使用。

## 记录与回放

默认关闭RGB录像，物理CSV和状态仍会保存。点击Record或启动时加`--record`开启实际执行RGB录制：

```powershell
& D:\miniconda\envs\stewart_rl\python.exe scripts\teleop_stewart_enhanced.py --record
```

终端输出SESSION目录；每次启动独立目录，每次Reset独立episode。

- `physics.csv.gz`：完整物理日志，边运行边写入。
- `states/state_*.npz`：每2000个物理步保存一块完整mjSTATE_INTEGRATION状态；正常退出会保存最后不足一块的数据。
- `state_chunks.jsonl`：分块顺序、全局索引、时间范围。
- `videos/actual_rgb_*.mp4`：实际执行画面，默认每1500帧分段（25fps，对应最多60秒已录制仿真时间）。关闭Record立即结束当前片段，再打开新建片段。
- `frames.jsonl`：帧与片段、物理步和qpos哈希的对应关系。
- `events.jsonl`、`summary.json`：完整操作与终止原因。
- `mirror_samples.jsonl`：只读显示镜像核验。

内存仅缓存一块状态、固定长度曲线、有限事件及镜像尾部；CSV、状态文件和录像仍会随运行时间占用磁盘。未声称磁盘故障或强制断电时能够完整归档。

结束后回放，替换为终端显示的实际episode目录：

```powershell
& D:\miniconda\envs\stewart_rl\python.exe scripts\teleop_stewart_enhanced.py --replay "__PROJECT_ROOT__\results\runs\你的SESSION\episode_000"
```

分段RGB回放保留ACTUAL EXECUTION CAPTURE来源标识；未录RGB时明确为RECORDED STATE REPLAY。历史回放目前会读取整回合CSV，特别长的归档回放内存仍随文件规模增加；持续运行时的实时缓存不受此影响。

## 可选有限实验

仍可明确指定预算，用于自动测试。只要指定的任一预算达到，就结束；不指定的预算不生效：

```powershell
& D:\miniconda\envs\stewart_rl\python.exe scripts\teleop_stewart_enhanced.py --headless --max-sim-seconds 0.2
```

无界headless运行会被CLI拒绝，避免没有可关闭窗口的后台无限运行。原有限短实验同时指定两个预算时仍保持历史记录格式与调度兼容。

没有修改模型、控制器、工作区边界或原安全检查，没有训练任何RL。
