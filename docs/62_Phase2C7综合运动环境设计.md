# Phase 2C-7 综合运动环境设计

本阶段研究50 mm升降叠加Roll/Pitch参考运动时的姿态抗扰，独立于Phase 2C-6的Home任务。Phase 2C-6的PARTIAL SUCCESS结论保持不变。本阶段不重新设计传统控制器。

## 参考与物理执行

`DynamicReference`采用五次时间缩放，默认1 s初始保持、6 s上升、1 s顶部保持、6 s下降、1 s末端保持，总长15 s。Z、旋转向量沿同一进度变化；Roll/Pitch组合用SO(3)旋转向量定义，不将两个欧拉角简单相加。参考包含真实位置、旋转矩阵、空间速度、角加速度、支链行程及速度、静力平衡力。

每种几何使用101个完整闭链IK节点、节点间中点IK核验与10001点行程复核。Hermite插值导数来自实际Jacobian。运动学查询只使用独立scratch数据；正式live状态始终由六路力执行器和`mj_step`推进。支链原生限位、被动关节处理、闭链保护和原有部分几何代理均保留。

控制层为原C4观测补偿（历史类内部名C3）、fourDlead以及冻结FF-VA Z前馈。FF-VA参数从Phase 2C-3B读取，不重新拟合。新包装层将FF与PPO力矩映射请求合成后送入**一次**实际共享预算器。反事实预算器仅用于同状态动作效果审计，不向机器人施加第二次命令。观测器仍接收最终受限控制命令。

实际附加力相对C0限制为每支链±5 N，附加力变化率20 N/s；原生执行器±400 N不变。20 N/s不是整条实际执行器力曲线的全局斜率约束，名义基础力及执行器动态会影响后者，两者单独记录。

投影比例表示合成请求触发共享预算投影的比例，可能包含基础补偿和前馈的影响，不能直接当作“PPO动作被完全拒绝的比例”。判断RL控制权限须同时查看同状态反事实差值、请求与接受力矩，以及真实驱动力差异。

## PPO接口

MuJoCo及传统控制均为1000 Hz；PPO为50 Hz，每次正常决策执行20个物理步。二维归一化动作映射到±0.05 N·m的Roll/Pitch请求，经当前Jacobian转为六支链附加力。请求、同状态可实现差值、最终命令、滞后内部驱动力、原生实际力分别记录，不能混为同一个量。

58维观测依次为：SO(3)误差3、实际角速度3、参考角速度3、位置误差3、线速度3、相对支链行程6、支链速度6、已知控制命令6、因果观测器估计6、同状态基础补偿6、上一请求2、上一接受残差2、参考旋转向量3、参考Z/速度/加速度3、参考角加速度3。

位置误差尺度为XY 0.2 mm、Z 0.05 mm；行程60 mm、支链速度30 mm/s；新增参考尺度为Z 50 mm、Z速度30 mm/s、Z加速度30 mm/s²、角加速度0.02 rad/s²。其余保留原因果姿态特征尺度。观测最终裁剪至±10，并报告裁剪比例。

Actor不读取真实外载、外载时序、任务等级、真实tau、内部drive或实际执行器力。已知参考的当前值及导数允许输入。新策略为58维新网络、零输出均值初始化，不能称作旧52维模型的完整迁移。旧模型只在独立迁移评价中使用其原52维特征和归一化，不改变权重。

## 奖励及终止

继承Reward-V2的五项结构：SO(3)/0.006°平方、角速度误差/0.003 rad/s平方乘0.2、位置误差按XY/Z独立尺度归一化平方乘0.1、实际接受残差/0.05 N·m平方乘0.001、实际接受残差变化率/2.5 N·m/s平方乘0.000025。每物理步总cost上限100，按比例缩放各项。

奖励是物理积分`-sum(cost*0.001)/0.020`，等价正常20步的负平均cost，保持Phase 2C-6决策尺度。保护后的真实保持步仍计入物理成本和总积分数。失败保留原大负终止惩罚，不能通过早停规避未来代价。

物理保护失败为terminated；完成固定物理时长为truncated，便于PPO在时间截断时处理价值bootstrap。是否稳定到达还需完整回合末0.5 s的实际位置/姿态阈值验收，不能只凭truncated宣布成功。课程切换及总训练预算造成的未完回合独立标记，不当作完整成功或完整失败。

CSV保存原始环境奖励；SB3遇到时间截断会在rollout内部加入终端价值bootstrap，因此NPZ中的相应奖励可与CSV不同。原始物理成本应与CSV复算，价值目标应按SB3的时间截断规则和GAE计算，不能混用两种口径。

## 训练协议

三种子42、123、2026；每种子Stage A 4096决策、Stage B 4096决策。共同门禁通过后累计至32768，余下24576决策用于Stage C。每512决策一次PPO优化，batch64、10 epochs、Actor/Critic各64×64、学习率0.0003。全量配置在`configs/phase2c7_*.yaml`（JSON兼容YAML）中冻结。

最终任务在训练前固定，并仅用于必要安全预检与冻结后的性能比较；安全预检已查看传统基线响应，因此报告称为独立冻结测试，不称完全未查看的盲测。最终固定三个种子的终点checkpoint，不挑最好种子，不根据最终结果修改奖励或预算。
