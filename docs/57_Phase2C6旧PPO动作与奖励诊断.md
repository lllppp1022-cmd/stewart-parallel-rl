# Phase 2C-6A 旧 PPO 动作与奖励诊断

## 数据和复算

Phase 2C-5 的三个最终 checkpoint 已通过 SHA-256、Actor/Critic 参数哈希和 52→2 接口核对。审计逐条读取旧训练和评价的 1 ms 压缩物理日志，并按决策编号关联原始高斯动作、Box 裁剪动作及终止事件。每个种子 8192 决策、163840 次积分、16 次更新。历史 checkpoint、配置、视频和报告保存在原位。

[奖励分量审计](../results/phase2c6_reward_component_audit.csv)将加载前、加载瞬间、加载后 100 ms、持续加载、卸载后 100 ms 和恢复阶段分开。五项分别计算积分、最小值、最大值与截断率，再与当时的逐决策奖励逐项比对。加载瞬间是加载后 100 ms 的子集，累计占比时只使用后者。复算 V1 的训练变化率代价占比在 seed42、123、2026 分别为 91.12%、91.66%、91.26%，姿态代价分别为 1.11%、0.93%、1.06%。这些是实际代价的归因，PPO 梯度还取决于回报、优势估计与样本分布。

## 请求、接受与真实响应

控制链为高斯动作 → Box 裁剪 → 每轴 ±0.05 N·m 请求 → 完整 Jacobian 力映射 → 和 fourDlead 叠加 → 共享限幅与限速 → 六支链命令 → 5 ms 合成滞后 drive → 原生执行器力。接受力矩是当前状态下有无 PPO 的受限命令差再经名义 Jacobian 映射。动作审计另用冻结真实力映射和精确 ZOH 建立同状态关断动作的滞后影子。影子量依赖已记录状态和参数，表示局部增量估计。匹配探针直接对比两次独立积分的实际执行器力与机器人响应。

[请求与接受审计](../results/phase2c6_action_authority.csv)记录裁剪、共享预算投影、硬限速边界及六支链信号。[滞后和时序表](../results/phase2c6_action_lag_windows.csv)细分加载与卸载后 20/40/60/100 ms。三个历史开发任务各窗口 RMS 的等权平均如下。

| 旧策略 | 请求 N·m | 接受命令 N·m | 滞后影子 N·m |
|---|---:|---:|---:|
| seed42 | 0.005289 | 0.005283 | 0.005323 |
| seed123 | 0.005898 | 0.005885 | 0.005882 |
| seed2026 | 0.005823 | 0.005747 | 0.005773 |

经典反馈在三个任务加载后首 100 ms 的接受增量方向均与外载相反。旧 PPO seed42 在三个任务均同向，seed2026 在 Roll 工况也同向。seed123 三个任务均反向，但较大的即时补偿也未转化为稳定的加载及卸载 IAE 优势。方向、时序和零扰动偏置都影响闭环；单靠比较动作大小无法诊断策略。

## 因果探针

在冻结的 T7 Home 工况，外载 +My 0.5 N·m，2.1 s 加载、3.8 s 卸载。从相同初态分别运行零动作及正负满幅 Mx/My。正负方向均在 20 ms 内出现对应轴角速度变化，100 ms 时仍可辨别。接受量与增量角速度、XY 耦合、命令/drive/执行器力的差值见[因果探针](../results/phase2c6_probe_causality.csv)。例如 +Mx 首 20 ms 的平均接受量为 +0.02539 N·m，角速度相对零动作增加约 0.0002306 rad/s，并有跨轴接受分量。

当前动作权限足以影响所测的 Home 扰动。满幅请求经过共享预算会显著衰减且发生跨轴耦合。对 1.2/2.4 N·m，单轴名义请求上界分别只有外载的约 4.17%/2.08%。这限制了直接抵消能力；能否改善闭环仍取决于方向、时序与扰动下的执行余量。历史策略落后有奖励信号尺度与加载方向的证据，尚无法将差距唯一归因于任一因素。
